> For agentic workers: use superpowers:executing-plans; authorised parallel CMS track shares the data contract.

**Goal:** Deliver reviewable public pages and backoffice matching supplied references, ready for later Supabase integration.
**Architecture:** Next.js App Router, typed shared content, browser-local preview adapter. Server metadata uses seed drafts; no indexing until production content/auth integration.
**Tech Stack:** Next.js, TypeScript, React, CSS, lucide-react.
**Spec:** docs/superpowers/specs/2026-11-23-portal-design.md

## Global Constraints
Native image generation only for new art. Source slicing allowed. Drive before GitHub. Four locales; English fallback. No production backend claims. Feature branch only.
